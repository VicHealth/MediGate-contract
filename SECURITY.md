# Security Policy

## Reporting a Vulnerability

We take the security of the MediGate smart contracts seriously. If you discover a security vulnerability:

1. **Do not** disclose it publicly, and **do not** submit it as a normal GitHub issue.
2. Report it privately via GitHub's **Security → Report a vulnerability** (private vulnerability reporting) on this repository.
3. Include a description of the issue, the affected contract, and steps to reproduce if possible.

## What to Expect

- Acknowledgment of your report within 48 hours.
- Regular updates on triage and fix progress.
- Credit for the discovery if you wish.

## Audit Status

These contracts have not been independently audited. They are under active development and should be treated as pre-audit / testnet-only. Do not deploy to Stellar mainnet or use them to custody real funds until an independent audit has been completed and this section is updated.
